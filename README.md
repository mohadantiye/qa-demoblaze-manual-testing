# qa-demoblaze-manual-testing

project overview
This repository contains a comprehensive manual testing project for the DemoBlaze e-commerce application

Scope
The project covers:
• User Registration
• Login
• Product Browsing
• Shopping Cart
• Checkout
• Contact Form

## Testing Types
- Functional Testing
- Negative Testing
- Exploratory Testing

## Key Findings
- Users can place orders without logging in (High severity)
- Weak input validation in signup, checkout, and contact form
- Session persists after closing browser

- Test Plan
